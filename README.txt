우리 가계부 - 부부 공유 버전

1. https://supabase.com 에서 무료 프로젝트를 생성합니다.
2. SQL Editor에 supabase.sql 내용을 붙여넣고 실행합니다.
3. Authentication > Providers > Email에서 이메일 로그인 사용을 확인합니다.
   이메일 인증을 사용하면 첫 가입 후 받은 인증 메일을 확인해야 합니다.
4. Project Settings / API Keys에서 프로젝트 URL과 publishable (또는 anon) 키를 확인합니다.
   절대로 service_role 또는 secret 키를 웹앱에 입력하지 마세요.
5. index.html을 HTTPS 정적 호스팅(예: Netlify, GitHub Pages)에 올려 같은 URL을 두 분이 접속합니다.
6. 앱 설정에서 동일한 Supabase URL, 공개 키, 이메일, 비밀번호로 로그인합니다.
   첫 접속 시 이메일 계정이 자동 가입되며, 이메일 인증이 필요할 수 있습니다.
7. 서로 다른 기기에서 입력하면 약 12초마다 변경 사항을 조회합니다.

주의:
- 한 계정을 공유하는 단순한 구조입니다. 각각의 개인 계정으로 공유하려면 초대/멤버십 구조가 추가로 필요합니다.
- 이미 입력한 로컬 데이터는 연결할 때 자동 업로드되지 않습니다. 먼저 JSON 백업하세요.
  클라우드 연결 후에는 백업 JSON 복원으로 올릴 수 있습니다.
- 두 기기가 같은 항목을 동시에 수정하면 마지막 저장 내용이 적용될 수 있습니다.
- 인터넷이 끊기면 공유 저장이 실패할 수 있으니 상태 메시지를 확인하세요.
- 브라우저에서 직접 file:// 로 열면 브라우저 보안 정책으로 연결이 제한될 수 있습니다. HTTPS 배포를 권장합니다.
- 민감한 가계부 데이터이므로 두 사람만 아는 별도의 강한 비밀번호를 사용하세요.

업데이트: 사용자 입력 대신 결제수단을 기록합니다. 공동 카드/하람 카드/현우 카드 등의 추천값을 선택하거나 직접 입력할 수 있습니다. 기존 DB의 person 열을 그대로 활용하므로 SQL 재실행이나 DB 변경은 필요하지 않습니다. 기존 기록의 나/배우자/공동 표기는 자동 변경되지 않으며 수정 화면에서 변경할 수 있습니다.
